1. 全体

外から入る口は、Proxy と Cloudflare の2つだけ。Proxy と Main は WireGuard でつなぎ、管理画面は Cloudflare Tunnel を通る。

2. 映像の経路

配信者の映像は Proxy から Main へ入り、media-worker で合成・エンコードして OME origin から配信する。視聴者へは Proxy の中継から届く。視聴パスワードは Main の player で照合する。

3. 管理画面とログイン

管理画面には Cloudflare Access のログインが要る。ログインは認証VMの authentik が Discord で確かめ、Discord のIDは仮名にして渡す。

4. 稼働監視（管理画面の「サーバー状態」）

読み取りだけの監視。Main の収集プログラムが Proxy の状態も取りに行き、まとめて書いたファイルを API が読む。
